Week 13

Sorting Algorithms: Mechanics, Stability & Trade-offs

  • Why sorting matters: turning chaotic data into monotonic search spaces.
  • Merge Sort: divide-and-conquer recurrence, stable merging, auxiliary space cost O(N).
  • QuickSort: Lomuto vs Hoare partitioning, pivot selection (median-of-three), worst-case O(N²) avoidance.
  • Why Java uses Dual-Pivot Quicksort for primitives and Timsort for objects (stability).
  • Non-comparison sorts: Counting Sort and Bucket Sort conceptually in O(N + K).
  • Custom sorting in Java: multi-field sorting via Comparator.comparing(...).thenComparing(...).
Week 14

Binary Trees & Binary Search Trees (BST)

  • Tree anatomy: root, leaf, height, depth, balanced vs skewed tree degenerations.
  • Depth-First Search (DFS): Preorder, Inorder, and Postorder recursion call-stack tracing.
  • Breadth-First Search (BFS): Level-order traversal using ArrayDeque with level-size bounding.
  • Tree metrics: Maximum depth, diameter of binary tree (bottom-up calculation), symmetric tree.
  • Path problems: Path Sum I/II/III, Maximum Path Sum (handling negative node values).
  • BST operations: Search, Insert, Inorder Successor, Delete node (handling 2-child case), Validate BST with bounds.
Week 15

Heaps & PriorityQueue: Top-K Streaming Optimization

  • Complete binary tree representation in an array: parent (i-1)/2, children 2i+1, 2i+2.
  • Heapify: sift-up (insert O(log N)) vs sift-down (delete O(log N)). Building a heap in O(N) linear time.
  • Java PriorityQueue API: Min-heap default, custom Max-heap comparator formulations.
  • The Top-K pattern: why maintaining a min-heap of size K yields O(N log K) instead of O(N log N) sort.
  • Top K Frequent Elements, K Closest Points to Origin, Merge K Sorted Lists.
  • The Dual-Heap pattern: Find Median from Data Stream using balanced max-heap and min-heap.
Week 16

Tries: Prefix Trees & Advanced String Search

  • The Trie mental model: multi-way tree structure where edges represent characters.
  • Node representation: TrieNode[] children = new TrieNode[26] vs HashMap for unicode.
  • Implement Trie (Prefix Tree): insert, search, and startsWith in O(L) time where L is word length.
  • Memory trade-offs: why Tries consume more RAM than HashSets, and when prefix-sharing wins.
  • Design Add and Search Words Data Structure (wildcard '.' search via DFS).
  • Trie + Backtracking: Word Search II (matrix grid traversal with prefix pruning).

Week 17

Graph Representations & Fundamental Traversals

  • Graph modeling: Vertices, edges, directed vs undirected, weighted vs unweighted.
  • Representations in Java: Adjacency Matrix vs List<List<Integer>> vs Map of lists.
  • Graph BFS: shortest path in unweighted networks, level-by-level spreading (Word Ladder).
  • Graph DFS: connected components, Number of Islands, Max Area of Island, Clone Graph.
  • Cycle detection: 3-color state tracking (0 = unvisited, 1 = visiting, 2 = visited) in directed graphs.
  • Bipartite graph validation using 2-coloring via BFS/DFS.
Week 18

Topological Sort, DSU & Shortest Paths

  • Directed Acyclic Graphs (DAG) and dependency resolution ordering.
  • Kahn’s Algorithm: indegree counting array + BFS queue. Course Schedule I & II.
  • Disjoint Set Union (DSU / Union-Find): parent array, find with path compression, union by rank.
  • DSU applications: Redundant Connection, Number of Provinces, dynamic graph connectivity.
  • Dijkstra’s Algorithm: Single-source shortest path with non-negative weights using PriorityQueue<int[]>.
  • Minimum Spanning Tree (MST): Kruskal's algorithm (Sort edges + DSU) vs Prim's algorithm.
Week 19

The Greedy Paradigm & Proof Intuitions

  • When can a locally optimal choice guarantee a global optimum? The "Greedy Stays Ahead" proof.
  • Interval Scheduling: Sorting by end time to maximize non-overlapping events.
  • Merge Intervals: Sorting by start time and maintaining running high-water mark.
  • Non-overlapping Intervals and Minimum Number of Arrows to Burst Balloons.
  • Jump Game I & II: tracking maximum reachable boundary without quadratic backtracking.
  • Gas Station: circular tour greedy invariant and total balance deficit reasoning.
Week 20

Dynamic Programming Foundations: 1D State Spaces

  • Why DP is not magic: it is brute-force recursion with cached overlapping subproblems.
  • The 6-Step DP Protocol: State definition → Recurrence relation → Base case → Order of iteration → Answer extraction → Space optimization.
  • Top-Down Memoization (Recursion + array) vs Bottom-Up Tabulation (iterative table).
  • Climbing Stairs and Min Cost Climbing Stairs (reducing space from O(N) to O(1)).
  • House Robber I & II (linear array vs circular array state breakdown).
  • Coin Change (unbounded choice, minimum count) vs Coin Change 2 (combination counting order).

Week 21

2D Grid DP, Knapsack & String Subsequence DP

  • Grid DP: Unique Paths I & II, Minimum Path Sum (state transition from top and left).
  • Space optimization on grids: reducing O(M × N) table down to single rolling 1D array O(N).
  • The Classic 0/1 Knapsack: decision of inclusion vs exclusion with capacity constraints.
  • Partition Equal Subset Sum and Target Sum (reducing problems to 0/1 Knapsack variants).
  • Longest Common Subsequence (LCS): match vs mismatch transitions across dual strings.
  • Edit Distance (Levenshtein distance): insert, delete, and replace operational cost analysis.
Week 22

Advanced DP Patterns & Bit Manipulation

  • Longest Increasing Subsequence (LIS): O(N²) DP vs O(N log N) Patience Sorting with Binary Search.
  • Interval DP: Longest Palindromic Subsequence, Matrix Chain Multiplication mindset.
  • Binary representation: AND, OR, XOR, NOT, left shift <<, right shift >>, unsigned shift >>>.
  • Bit manipulation tricks: n & (n-1) to clear lowest set bit, n & (-n) to isolate lowest bit.
  • Single Number I & II (XOR cancellation), Counting Bits, Reverse Bits.
  • State compression: representing subsets of up to 20 elements as single 32-bit integer bitmasks.
Week 23

  • Decoding hidden problem statements: stripping away fluff narrative to reveal core algorithmic graph/array abstractions.
  • Debugging edge case failures on hidden test cases (32-bit integer overflow, negative coordinates, disconnected graphs).
