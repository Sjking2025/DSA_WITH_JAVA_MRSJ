Section 03

The 24-Week Master Curriculum & 20 Phases

A progressive, mathematically sound 6-month engineering curriculum structured across 20 distinct conceptual phases. Designed for students who demand deep understanding over superficial problem counts.

The 20 Conceptual Phases: Core Priority Hierarchy

TIER 1 — MUST KNOW

Highest Frequency

Phases 0–10, 13–14, 16–18. Arrays, Strings, Hashing, Two Pointers, Sliding Window, Prefix Sum, Linked Lists, Stacks, Queues, Binary Search, Trees, Heaps, Graph BFS/DFS, TopoSort, DSU, Dijkstra, and 1D/2D DP. Tested in 95% of software engineering interviews.

TIER 2 — GOOD TO KNOW

Product Rounds

Phases 11–12, 15, 19. Backtracking, Sorting internals (Merge/Quick), Tries, Bit Manipulation, and Monotonic Queue. Differentiates candidates from passing to strong hire in product company rounds.

TIER 3 — ADVANCED / ROLE DEPENDENT

Specialized / OA

Phase 20. AVL Trees, Segment Trees, Fenwick Trees, Binary Lifting (LCA), and State Compression / Bitmask DP. Introduced only after fundamentals are thoroughly mastered for hard Online Assessments.

Week 1

Java Memory Model & Computational Logic

  • Mental Model: How CPU registers, L1/L2 caches, RAM, and JVM stack/heap communicate.
  • Primitive variables (int, long, double) vs reference handles on heap.
  • Control flow branching: if/else, switch expressions, short-circuit evaluation semantics.
  • Loop mechanics: while vs for; boundary condition anatomy (< vs <=).
  • Phase 0 Drill: Converting English word problems into state variables and loop invariants.
  • Code Lab: Building an interactive dry-run table tracker in Java 21 console.
Week 2

Arrays, String Internals & Memory Traversal

  • Array layout in memory: contiguous indexing, base address calculation address + (i * size).
  • Linear scan, single-pass running state, and frequency counting with direct addressing array.
  • String pool mechanics, immutability, and why s += char degrades to O(N²).
  • High-efficiency string manipulation using StringBuilder and char[] buffers.
  • 2D Arrays & Matrix traversals: row-major vs column-major cache locality.
  • Classic Problems: Reverse array in-place, Two Sum (brute-force vs sorted), Valid Anagram.
Week 3

OOP Essentials for Algorithmic Structures

  • Classes, objects, constructors, and encapsulation relevant strictly to DSA.
  • Value semantics vs reference semantics: why passing an array mutates caller state.
  • Writing custom classes for complex state: Pair<K, V>, Node, and Java 17+ record.
  • Generics fundamentals: type erasure and why new T[] is illegal in Java.
  • Comparable<T> vs Comparator<T>: modern lambda syntax Comparator.comparingInt(...).
  • Trap Avoidance: Overriding equals() and hashCode() for custom hash keys.
Week 4

Mathematical Complexity & The Complexity Lab

  • Big-O (Upper bound), Big-Omega (Lower bound), and Big-Theta (Tight bound) formal definitions.
  • Deriving complexity from code: single loops, nested loops, non-linear step increments (i *= 2).
  • Analyzing logarithmic complexity: why halving search spaces results in O(log N).
  • Linearithmic O(N log N), Quadratic O(N²), and Exponential O(2ⁿ) bounds.
  • Amortized complexity: deep dive into ArrayList.add() capacity doubling.
  • Space complexity: auxiliary space vs input memory, recursive call stack consumption.

The suite captures nanosecond CPU times and heap memory allocations via Runtime.getRuntime(), automatically outputting empirical validation tables and identifying performance degradation points.

Demonstrates
Empirical vs theoretical Big-O, garbage collection impact, loop mechanics, Java 21 records

Month 02 • Weeks 5–8

Core Linear DSA & Invariant-Driven Patterns

Phase 2: In-Place Arrays • Phase 3: Deep Hashing • Phase 4: Two Pointers • Phase 5: Sliding Window • Phase 6: Prefix Sum
Two Pointers Sliding Window (Fixed/Dynamic) HashMap Internals Prefix Sum Difference Array Kadane's Algorithm Subarray Invariants
Week 5

Array In-Place Modifications & Matrix Traversals

  • The in-place boundary invariant: dividing an array into [Processed | Unprocessed].
  • Removing duplicates from sorted array without auxiliary allocation in O(1) space.
  • Dutch National Flag algorithm: 3-way partitioning with low, mid, and high pointers.
  • Rotate array: 3-reversal algorithm and cyclic replacements.
  • Matrix patterns: spiral traversal, diagonal walk, 90-degree in-place matrix rotation.
  • Kadane's algorithm: dynamic subproblem observation — "Should I extend the subarray or start fresh?"
Week 6

Hashing Foundations & Lookup Optimization

  • The core question: "What repeated O(N) linear search can I reduce to O(1) amortized lookup?"
  • HashMap internal deep-dive: hashCode, bucket index bitmask h & (n-1), collision resolution.
  • Complement lookup pattern: Two Sum, 3-Sum (Hash vs Two-Pointer trade-offs).
  • Frequency mapping and frequency-bucket grouping (Group Anagrams).
  • Set lookups for sequence reconstruction: Longest Consecutive Sequence in O(N) time.
  • Subarray Sum Equals K: combining prefix sum cumulative state with HashMap lookup in a single pass.
Week 7

Two Pointers: Converging & Fast-Slow Patterns

  • Opposite-direction pointers: searching sorted spaces, trapping rain water, container with most water.
  • The elimination invariant: proving mathematically why the discarded element can never be part of a better solution.
  • Same-direction read/write pointers for in-place compaction and partitioning.
  • Fast and slow pointers (Floyd's Tortoise and Hare) conceptually introduced for arrays.
  • Triplets and Quadruplets: sorting + two-pointer reduction with strict duplicate avoidance.
  • Interview execution: verbalizing the monotonicity invariant that allows pointer movement.
Week 8

Sliding Window & Difference Arrays

  • Why brute force enumerates O(N²) subarrays and how sliding window reuses overlapping state.
  • Fixed Window Pattern: Maximum sum subarray of size K, first negative integer in window.
  • Dynamic Expand-Shrink Pattern: Longest substring without repeating characters, fruit into baskets.
  • Frequency-Constrained Windows: Minimum window substring (the ultimate sliding window test).
  • Prefix sums for static O(1) range sum queries; 2D prefix sums for matrix sub-rectangles.
  • Difference arrays: performing range updates [L, R] += val in O(1) time.
Milestone Project 2

High-Throughput Telemetry Sliding Window Aggregator

Students design a real-time event analytics stream engine. The system processes an incoming stream of millions of network timestamp packets, using fixed and variable sliding windows alongside prefix difference arrays to calculate moving percentiles, detect traffic anomalies, and locate anomalous bursts in guaranteed O(1) amortized time per packet without storing the entire event history.

Demonstrates
Dynamic sliding window, prefix sums, difference array updates, memory-bounded Java streams
Interview Assessment
Live derivation of Minimum Window Substring, Trapping Rain Water, and Subarray Sum Equals K

Month 03 • Weeks 9–12

Non-Linear Structures, Monotonicity & Search Space Decomposition

Phase 7: Linked Lists • Phase 8: Stacks & Queues • Phase 9: Binary Search • Phase 10 & 11: Recursion & Backtracking
Pointer Manipulation Monotonic Stack Monotonic Queue Binary Search on Answer Recursion Trees Backtracking State Undo Branch Pruning
Week 9

Linked Lists: Pointer Mastery & Cycle Invariants

  • Node representation and reference pointer manipulation in memory (drawing box diagrams).
  • The Dummy Head Node technique: eliminating edge cases for head insertions and deletions.
  • Singly vs Doubly Linked Lists: internal trade-offs and sentinel nodes.
  • Iterative vs Recursive in-place reversal: reversing a sublist between positions [L, R].
  • Floyd's Cycle Detection algorithm: proving why slow and fast meet and deriving start-of-cycle node.
  • Merging two sorted lists and reordering list (combining mid-find, reverse, and merge).
Week 10

Stacks, Deques & Monotonic Structures

  • LIFO and FIFO mechanics implemented via Java's ArrayDeque.
  • Valid Parentheses, evaluating Reverse Polish Notation (RPN), and expression parsing.
  • Monotonic Stack: What invariant makes it work? Why does it discard non-optimal candidates?
  • Next Greater Element, Daily Temperatures, and Largest Rectangle in Histogram in O(N).
  • Monotonic Queue: Sliding Window Maximum using deque to maintain decreasing candidates.
  • MinStack design: maintaining min in O(1) using paired values or value-differential encoding.
Week 11

Binary Search: Searching Monotonic Predicates

  • Moving beyond simple array search: viewing binary search as finding a boundary where a condition flips F F F T T T.
  • Lower bound, Upper bound, First Occurrence, and Last Occurrence without off-by-one errors.
  • Search in Rotated Sorted Array: identifying which half remains strictly sorted.
  • Find Peak Element: binary searching in non-sorted arrays using local slope invariants.
  • Binary Search on Answer: Formulating feasibility functions boolean isValid(mid).
  • Classic problems: Koko Eating Bananas, Capacity To Ship Packages, Book Allocation Problem.
Week 12

Recursion Anatomy & Exhaustive Backtracking

  • The call stack visualized: activation records, local state, base cases, and return bubbling.
  • Drawing recursion decision trees before writing a single line of Java code.
  • The 4-step Backtracking protocol: Choice → Explore → Undo / Restore State → Next Choice.
  • Subsets (Cascading vs Backtracking), Combinations, and Combination Sum variants.
  • Permutations with and without duplicates (in-place swap vs boolean visited array).
  • Branch pruning: recognizing invalid subtrees early to avoid combinatorial explosion (N-Queens, Sudoku Solver).
Milestone Project 3

Production Undo/Redo Engine & Expression Calculator

Students implement a multi-threaded text editing command engine and mathematical formula parser. The system utilizes dual ArrayDeque stacks for O(1) state snapshotting, a monotonic queue to calculate rolling minimum/maximum cursor latency, and a recursive descent parser capable of evaluating complex nested algebraic expressions with parentheses, operator precedence, and variable substitutions.

Demonstrates
ArrayDeque stacks, monotonic queue, recursive descent parsing, state rollback invariants
Interview Assessment

Month 04 • Weeks 13–16

Hierarchical Structures, Top-K Optimization & Prefix Trees

Phase 12: Sorting • Phase 13: Binary Trees & BST • Phase 14: Heaps & PriorityQueue • Phase 15: Tries
Tree DFS / BFS Binary Search Tree Min / Max Heap Dual Heap Pattern Trie Prefix Search Sorting Stability Custom Comparators
Week 13

Sorting Algorithms: Mechanics, Stability & Trade-offs

  • Why sorting matters: turning chaotic data into monotonic search spaces.
  • Merge Sort: divide-and-conquer recurrence, stable merging, auxiliary space cost O(N).
  • QuickSort: Lomuto vs Hoare partitioning, pivot selection (median-of-three), worst-case O(N²) avoidance.
  • Why Java uses Dual-Pivot Quicksort for primitives and Timsort for objects (stability).
  • Non-comparison sorts: Counting Sort and Bucket Sort conceptually in O(N + K).
  • Custom sorting in Java: multi-field sorting via Comparator.comparing(...).thenComparing(...).
Week 14

Binary Trees & Binary Search Trees (BST)

  • Tree anatomy: root, leaf, height, depth, balanced vs skewed tree degenerations.
  • Depth-First Search (DFS): Preorder, Inorder, and Postorder recursion call-stack tracing.
  • Breadth-First Search (BFS): Level-order traversal using ArrayDeque with level-size bounding.
  • Tree metrics: Maximum depth, diameter of binary tree (bottom-up calculation), symmetric tree.
  • Path problems: Path Sum I/II/III, Maximum Path Sum (handling negative node values).
  • BST operations: Search, Insert, Inorder Successor, Delete node (handling 2-child case), Validate BST with bounds.
Week 15

Heaps & PriorityQueue: Top-K Streaming Optimization

  • Complete binary tree representation in an array: parent (i-1)/2, children 2i+1, 2i+2.
  • Heapify: sift-up (insert O(log N)) vs sift-down (delete O(log N)). Building a heap in O(N) linear time.
  • Java PriorityQueue API: Min-heap default, custom Max-heap comparator formulations.
  • The Top-K pattern: why maintaining a min-heap of size K yields O(N log K) instead of O(N log N) sort.
  • Top K Frequent Elements, K Closest Points to Origin, Merge K Sorted Lists.
  • The Dual-Heap pattern: Find Median from Data Stream using balanced max-heap and min-heap.
Week 16

Tries: Prefix Trees & Advanced String Search

  • The Trie mental model: multi-way tree structure where edges represent characters.
  • Node representation: TrieNode[] children = new TrieNode[26] vs HashMap for unicode.
  • Implement Trie (Prefix Tree): insert, search, and startsWith in O(L) time where L is word length.
  • Memory trade-offs: why Tries consume more RAM than HashSets, and when prefix-sharing wins.
  • Design Add and Search Words Data Structure (wildcard '.' search via DFS).
  • Trie + Backtracking: Word Search II (matrix grid traversal with prefix pruning).
Milestone Project 4

In-Memory Autocomplete Search Engine & Streaming Median Monitor

Students construct an enterprise search suggestion engine. The system indexes millions of search query strings into a memory-efficient prefix Trie with frequency weights, returning ranked top-10 autocomplete recommendations in sub-millisecond response times. A companion analytics service maintains running 50th, 90th, and 99th percentile metrics on query lengths using a dual-heap architecture.

Demonstrates
Prefix Trie with frequency nodes, dual-heap streaming medians, comparator chaining, memory profiling
Interview Assessment

Month 05 • Weeks 17–20

Graphs, Disjoint Sets, Greedy Proofs & Dynamic Programming

Phase 16: Graphs & DSU • Phase 17: Greedy Paradigm • Phase 18: DP Foundations (Recursion → Memo → Tabulation)
Graph Adjacency List BFS / DFS Traversals Topological Sort (Kahn's) Union-Find / DSU Dijkstra Shortest Path Greedy Invariants 1D Dynamic Programming
Week 17

Graph Representations & Fundamental Traversals

  • Graph modeling: Vertices, edges, directed vs undirected, weighted vs unweighted.
  • Representations in Java: Adjacency Matrix vs List<List<Integer>> vs Map of lists.
  • Graph BFS: shortest path in unweighted networks, level-by-level spreading (Word Ladder).
  • Graph DFS: connected components, Number of Islands, Max Area of Island, Clone Graph.
  • Cycle detection: 3-color state tracking (0 = unvisited, 1 = visiting, 2 = visited) in directed graphs.
  • Bipartite graph validation using 2-coloring via BFS/DFS.
Week 18

Topological Sort, DSU & Shortest Paths

  • Directed Acyclic Graphs (DAG) and dependency resolution ordering.
  • Kahn’s Algorithm: indegree counting array + BFS queue. Course Schedule I & II.
  • Disjoint Set Union (DSU / Union-Find): parent array, find with path compression, union by rank.
  • DSU applications: Redundant Connection, Number of Provinces, dynamic graph connectivity.
  • Dijkstra’s Algorithm: Single-source shortest path with non-negative weights using PriorityQueue<int[]>.
  • Minimum Spanning Tree (MST): Kruskal's algorithm (Sort edges + DSU) vs Prim's algorithm.
Week 19

The Greedy Paradigm & Proof Intuitions

  • When can a locally optimal choice guarantee a global optimum? The "Greedy Stays Ahead" proof.
  • Interval Scheduling: Sorting by end time to maximize non-overlapping events.
  • Merge Intervals: Sorting by start time and maintaining running high-water mark.
  • Non-overlapping Intervals and Minimum Number of Arrows to Burst Balloons.
  • Jump Game I & II: tracking maximum reachable boundary without quadratic backtracking.
  • Gas Station: circular tour greedy invariant and total balance deficit reasoning.
Week 20

Dynamic Programming Foundations: 1D State Spaces

  • Why DP is not magic: it is brute-force recursion with cached overlapping subproblems.
  • The 6-Step DP Protocol: State definition → Recurrence relation → Base case → Order of iteration → Answer extraction → Space optimization.
  • Top-Down Memoization (Recursion + array) vs Bottom-Up Tabulation (iterative table).
  • Climbing Stairs and Min Cost Climbing Stairs (reducing space from O(N) to O(1)).
  • House Robber I & II (linear array vs circular array state breakdown).
  • Coin Change (unbounded choice, minimum count) vs Coin Change 2 (combination counting order).
Milestone Project 5

Distributed Microservice Dependency Resolver & Network Router

Students architect a distributed build and deployment dependency analyzer. Given thousands of interdependent microservices with compile dependencies and latency weights, the engine detects cyclic dependency deadlocks via 3-color DFS, determines the parallel execution stages using Kahn's topological sort, locates network fault partitions using DSU, and computes optimal request dispatch routes using Dijkstra's algorithm.

Demonstrates

Week 21

2D Grid DP, Knapsack & String Subsequence DP

  • Grid DP: Unique Paths I & II, Minimum Path Sum (state transition from top and left).
  • Space optimization on grids: reducing O(M × N) table down to single rolling 1D array O(N).
  • The Classic 0/1 Knapsack: decision of inclusion vs exclusion with capacity constraints.
  • Partition Equal Subset Sum and Target Sum (reducing problems to 0/1 Knapsack variants).
  • Longest Common Subsequence (LCS): match vs mismatch transitions across dual strings.
  • Edit Distance (Levenshtein distance): insert, delete, and replace operational cost analysis.
Week 22

Advanced DP Patterns & Bit Manipulation

  • Longest Increasing Subsequence (LIS): O(N²) DP vs O(N log N) Patience Sorting with Binary Search.
  • Interval DP: Longest Palindromic Subsequence, Matrix Chain Multiplication mindset.
  • Binary representation: AND, OR, XOR, NOT, left shift <<, right shift >>, unsigned shift >>>.
  • Bit manipulation tricks: n & (n-1) to clear lowest set bit, n & (-n) to isolate lowest bit.
  • Single Number I & II (XOR cancellation), Counting Bits, Reverse Bits.
  • State compression: representing subsets of up to 20 elements as single 32-bit integer bitmasks.
Week 23

Tier-1 Online Assessment (OA) Simulation & Speed Engineering

  • Online Assessment environment dynamics: HackerRank, CodeSignal, LeetCode OA mechanics.
  • Handling huge input bounds: reading constraints to immediately determine acceptable Big-O.
  • Fast I/O in Java: BufferedReader and StringTokenizer vs slow Scanner.
  • Time management under pressure: 2 medium problems in 60 minutes; 3 problems in 90 minutes.
  • Decoding hidden problem statements: stripping away fluff narrative to reveal core algorithmic graph/array abstractions.
  • Debugging edge case failures on hidden test cases (32-bit integer overflow, negative coordinates, disconnected graphs).
Week 24

The Interview Readiness Gauntlet & Final Placement Sprint

  • The 10-Step Interview Communication Protocol practiced live under strict audio recording.
  • How to recover when you get stuck: structured inquiry, asking clarifying questions, reverting to verified invariants.
  • Defending technical trade-offs: why your approach beats the interviewer's suggested alternative.
  • Code Review & Refactoring: writing clean, production-grade variable names and helper methods without IDE autocomplete.
  • Resume engineering for DSA: framing algorithmic projects with concrete metrics and architecture bullets.
  • Completing the 8-Round Interview Readiness Gauntlet and receiving the comprehensive Diagnostic Audit Report.
