Section 04

The 40-Pattern Recognition Engine & Problem Protocol

Every technical interview problem is a combination of known mathematical invariants masked behind an unfamiliar narrative. Master the 14-step decomposition protocol and the 40 foundational algorithmic patterns with structural "tells" and idiomatic Java 21 templates.

The Mandatory 14-Step Problem-Solving Protocol

01Read & ExtractIdentify input types, output format, array constraints, and hidden assumptions (e.g. empty, negatives, sorted).
02Restate AloudExplain the problem in your own words in 30 seconds without reading verbatim from the screen.
03Brute ForceFormulate the simplest correct solution (usually exhaustive search or nested loops).
04Brute Force Big-OCalculate time and space complexity of the brute force solution (e.g. O(N²), O(2ⁿ)).

P01

Linear Scan & Running State

Linear & Arrays
Problem Signal ("The Tell")
Single sequence, find maximum/minimum, running sum, or first violation without sorting.
Core Invariant
At step i, the running variable holds the optimal answer for sub-array [0...i-1].
Time & Auxiliary Space
Time: O(N) single pass • Space: O(1) auxiliary variables.
Canonical Problems
Best Time to Buy and Sell Stock I, Running Sum of 1D Array, Maximum Subarray (Kadane).
int minPrice = Integer.MAX_VALUE, maxProfit = 0; for (int price : prices) { minPrice = Math.min(minPrice, price); maxProfit = Math.max(maxProfit, price - minPrice); } return maxProfit;

Sliding Window (Fixed Size K)

Windows & Pointers
Problem Signal ("The Tell")
Calculate metric on every contiguous subarray of exact size K.
Core Invariant
Maintain state of size K by adding arr[right] and discarding arr[right - K] in O(1).
Time & Auxiliary Space
Time: O(N) single scan • Space: O(1) auxiliary running window.
Canonical Problems
Maximum Average Subarray I, First Negative in Every Window of Size K, Diet Plan Performance.

Binary Search (Boundary & Rotated Space)

Windows & Pointers
Problem Signal ("The Tell")
Sorted array, find first/last occurrence, or search in array rotated at unknown pivot.
Core Invariant
At least one half [left...mid] or [mid...right] remains strictly sorted.
Time & Auxiliary Space
Time: O(log N) • Space: O(1) iterative boundary contraction.
Canonical Problems
Search in Rotated Sorted Array, Find First and Last Position of Element, Find Minimum in Rotated Array.

P26

Disjoint Set Union (DSU / Union-Find)

Graphs & DSU
Problem Signal ("The Tell")
Dynamic connectivity, redundant edge detection, finding number of connected components.
Core Invariant
Path compression flattens tree; Union-by-Rank attaches smaller tree under larger root: α(N) ≈ O(1).
Time & Auxiliary Space
Find / Union: O(α(N)) amortized nearly O(1) • Space: O(N) parent and rank arrays.
Canonical Problems
Number of Provinces, Redundant Connection, Accounts Merge, Graph Valid Tree, Kruskal's MST.
class DSU { int[] parent, rank; public DSU(int n) { parent = new int[n]; rank = new int[n]; for (int i = 0; i < n; i++) parent[i] = i; } public int find(int i) { if (parent[i] == i) return i; return parent[i] = find(parent[i]); // Path compression } public boolean union(int x, int y) { int rootX = find(x), rootY = find(y); if (rootX == rootY) return false; // Cycle detected if (rank[rootX] < rank[rootY]) parent[rootX] = rootY; else if (rank[rootX] > rank[rootY]) parent[rootY] = rootX; else { parent[rootY] = rootX; rank[rootX]++; } return true; } }
