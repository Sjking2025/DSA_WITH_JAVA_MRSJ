Section 03

The 24-Week Master Curriculum Roadmap

A progressive, no-compromises 6-month engineering curriculum structured across 20 distinct conceptual phases. Designed for learners who demand deep mastery over superficial problem counts.

01
Month 01 • Weeks 1–4

Programming Foundations, Memory & Computational Complexity

Phase 0: Think Like a Programmer • Phase 1: Complexity Analysis • Java Foundations for DSA
JVM Architecture Stack vs Heap Primitive vs Reference StringBuilder Deriving Big-O Amortized Analysis Problem Decomposition
Week 1

Java Memory Model & Computational Logic

  • Mental Model: How CPU registers, L1/L2 caches, RAM, and JVM stack/heap communicate.
  • Primitive variables (int, long, double) vs reference handles on heap.
  • Control flow branching: if/else, switch expressions, short-circuit evaluation semantics.
  • Loop mechanics: while vs for; boundary condition anatomy (< vs <=).
  • Phase 0 Drill: Converting English word problems into state variables and loop invariants.
  • Code Lab: Building an interactive dry-run table tracker in Java 21 console.
Week 2

Arrays, String Internals & Memory Traversal

  • Array layout in memory: contiguous indexing, base address calculation address + (i * size).
  • Linear scan, single-pass running state, and frequency counting with direct addressing array.
  • String pool mechanics, immutability, and why s += char degrades to O(N²).
  • High-efficiency string manipulation using StringBuilder and char[] buffers.
  • 2D Arrays & Matrix traversals: row-major vs column-major cache locality.
  • Classic Problems: Reverse array in-place, Two Sum (brute-force vs sorted), Valid Anagram.
Week 3

OOP Essentials for Algorithmic Structures

  • Classes, objects, constructors, and encapsulation relevant strictly to DSA.
  • Value semantics vs reference semantics: why passing an array mutates caller state.
  • Writing custom classes for complex state: Pair<K, V>, Node, and Java 17+ record.
  • Generics fundamentals: type erasure and why new T[] is illegal in Java.
  • Comparable<T> vs Comparator<T>: modern lambda syntax Comparator.comparingInt(...).
  • Trap Avoidance: Overriding equals() and hashCode() for custom hash keys.
Week 4

Mathematical Complexity & The Complexity Lab

  • Big-O (Upper bound), Big-Omega (Lower bound), and Big-Theta (Tight bound) formal definitions.
  • Deriving complexity from code: single loops, nested loops, non-linear step increments (i *= 2).
  • Analyzing logarithmic complexity: why halving search spaces results in O(log N).
  • Linearithmic O(N log N), Quadratic O(N²), and Exponential O(2ⁿ) bounds.
  • Amortized complexity: deep dive into ArrayList.add() capacity doubling.
  • Space complexity: auxiliary space vs input memory, recursive call stack consumption.
Milestone Project 1

Algorithmic Benchmarking Suite & JVM Complexity Profiler

Students engineer a standalone Java tool that executes linear, logarithmic, quadratic, and exponential routines across varying input sizes (N = 10 to 100,000,000). The suite captures nanosecond CPU times and heap memory allocations via Runtime.getRuntime(), automatically outputting Big-O curvature plots and empirical validation tables in console.

Demonstrates
Empirical vs theoretical Big-O, garbage collection impact, loop mechanics, Java 21 records
Interview Assessment
Deriving complexity on 10 live code snippets, defending space trade-offs, zero compile bugs
02
Month 02 • Weeks 5–8

Core Linear DSA & Invariant-Driven Patterns

Phase 2: In-Place Arrays • Phase 3: Deep Hashing • Phase 4: Two Pointers • Phase 5: Sliding Window • Phase 6: Prefix Sum
Two Pointers Sliding Window (Fixed/Dynamic) HashMap Internals Prefix Sum Difference Array Kadane's Algorithm Subarray Invariants
Week 5

Array In-Place Modifications & Matrix Traversals

  • The in-place boundary invariant: dividing an array into [Processed | Unprocessed].
  • Removing duplicates from sorted array without auxiliary allocation in O(1) space.
  • Dutch National Flag algorithm: 3-way partitioning with low, mid, and high pointers.
  • Rotate array: 3-reversal algorithm and cyclic replacements.
  • Matrix patterns: spiral traversal, diagonal walk, 90-degree in-place matrix rotation.
  • Kadane's algorithm: dynamic subproblem observation — "Should I extend the subarray or start fresh?"
Week 6

Hashing Foundations & Lookup Optimization

  • The core question: "What repeated O(N) linear search can I reduce to O(1) amortized lookup?"
  • HashMap internal deep-dive: hashCode, bucket index bitmask h & (n-1), collision resolution.
  • Complement lookup pattern: Two Sum, 3-Sum (Hash vs Two-Pointer trade-offs).
  • Frequency mapping and frequency-bucket grouping (Group Anagrams).
  • Set lookups for sequence reconstruction: Longest Consecutive Sequence in O(N) time.
  • Subarray Sum Equals K: combining prefix sum cumulative state with HashMap lookup in a single pass.
Week 7

Two Pointers: Converging & Fast-Slow Patterns

  • Opposite-direction pointers: searching sorted spaces, trapping rain water, container with most water.
  • The elimination invariant: proving mathematically why the discarded element can never be part of a better solution.
  • Same-direction read/write pointers for in-place compaction and partitioning.
  • Fast and slow pointers (Floyd's Tortoise and Hare) conceptually introduced for arrays.
  • Triplets and Quadruplets: sorting + two-pointer reduction with strict duplicate avoidance.
  • Interview execution: verbalizing the monotonicity invariant that allows pointer movement.
Week 8

Sliding Window & Difference Arrays

  • Why brute force enumerates O(N²) subarrays and how sliding window reuses overlapping state.
  • Fixed Window Pattern: Maximum sum subarray of size K, first negative integer in window.
  • Dynamic Expand-Shrink Pattern: Longest substring without repeating characters, fruit into baskets.
  • Frequency-Constrained Windows: Minimum window substring (the ultimate sliding window test).
  • Prefix sums for static O(1) range sum queries; 2D prefix sums for matrix sub-rectangles.
  • Difference arrays: performing range updates [L, R] += val in O(1) time.
Milestone Project 2

High-Throughput Telemetry Sliding Window Aggregator

Students design a real-time event analytics stream engine. The system processes an incoming stream of millions of network timestamp packets, using fixed and variable sliding windows alongside prefix difference arrays to calculate moving percentiles, detect traffic anomalies, and locate anomalous bursts in guaranteed O(1) amortized time per packet without storing the entire event history.

Demonstrates
Dynamic sliding window, prefix sums, difference array updates, memory-bounded Java streams
Interview Assessment
Live derivation of Minimum Window Substring, Trapping Rain Water, and Subarray Sum Equals K
03
Month 03 • Weeks 9–12

Non-Linear Structures, Monotonicity & Search Space Decomposition

Phase 7: Linked Lists • Phase 8: Stacks & Queues • Phase 9: Binary Search • Phase 10 & 11: Recursion & Backtracking
Pointer Manipulation Monotonic Stack Monotonic Queue Binary Search on Answer Recursion Trees Backtracking State Undo Branch Pruning
Week 9

Linked Lists: Pointer Mastery & Cycle Invariants

  • Node representation and reference pointer manipulation in memory (drawing box diagrams).
  • The Dummy Head Node technique: eliminating edge cases for head insertions and deletions.
  • Singly vs Doubly Linked Lists: internal trade-offs and sentinel nodes.
  • Iterative vs Recursive in-place reversal: reversing a sublist between positions [L, R].
  • Floyd's Cycle Detection algorithm: proving why slow and fast meet and deriving start-of-cycle node.
  • Merging two sorted lists and reordering list (combining mid-find, reverse, and merge).
Week 10

Stacks, Deques & Monotonic Structures

  • LIFO and FIFO mechanics implemented via Java's ArrayDeque.
  • Valid Parentheses, evaluating Reverse Polish Notation (RPN), and expression parsing.
  • Monotonic Stack: What invariant makes it work? Why does it discard non-optimal candidates?
  • Next Greater Element, Daily Temperatures, and Largest Rectangle in Histogram in O(N).
  • Monotonic Queue: Sliding Window Maximum using deque to maintain decreasing candidates.
  • MinStack design: maintaining min in O(1) using paired values or value-differential encoding.
Week 11

Binary Search: Searching Monotonic Predicates

  • Moving beyond simple array search: viewing binary search as finding a boundary where a condition flips F F F T T T.
  • Lower bound, Upper bound, First Occurrence, and Last Occurrence without off-by-one errors.
  • Search in Rotated Sorted Array: identifying which half remains strictly sorted.
  • Find Peak Element: binary searching in non-sorted arrays using local slope invariants.
  • Binary Search on Answer: Formulating feasibility functions boolean isValid(mid).
  • Classic problems: Koko Eating Bananas, Capacity To Ship Packages, Book Allocation Problem.
Week 12

Recursion Anatomy & Exhaustive Backtracking

  • The call stack visualized: activation records, local state, base cases, and return bubbling.
  • Drawing recursion decision trees before writing a single line of Java code.
  • The 4-step Backtracking protocol: Choice → Explore → Undo / Restore State → Next Choice.
  • Subsets (Cascading vs Backtracking), Combinations, and Combination Sum variants.
  • Permutations with and without duplicates (in-place swap vs boolean visited array).
  • Branch pruning: recognizing invalid subtrees early to avoid combinatorial explosion (N-Queens, Sudoku Solver).
Milestone Project 3

Production Undo/Redo Engine & Expression Calculator

Students implement a multi-threaded text editing command engine and mathematical formula parser. The system utilizes dual ArrayDeque stacks for O(1) state snapshotting, a monotonic queue to calculate rolling minimum/maximum cursor latency, and a recursive descent compiler capable of evaluating complex nested algebraic expressions with parentheses, operator precedence, and variable substitutions.

Demonstrates
ArrayDeque stacks, monotonic queue, recursive descent parsing, state rollback invariants
Interview Assessment
Live coding of Largest Rectangle in Histogram, Rotated Binary Search, and N-Queens
